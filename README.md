# Develop IA Web Solutions

An elite, high-performance static website demonstrating a technical synthesis of architectural stability and cutting-edge Artificial Intelligence integration. Designed for technical founders, developers, and enterprise stakeholders.

---

## 🌌 Visual Aesthetic & Design Philosophy

The website is built following **Tech-Minimalism** guidelines with a dark-mode-first aesthetic:
* **The Palette**: "Midnight-to-Electric" spectrum. Deep slate bases prevent screen fatigue, while **Electric Cyan** accents spotlight interactive modules and AI operations.
* **Typography**: Clean geometric lines of **Geist** for modern interfaces coupled with high-density data metadata rendered in **JetBrains Mono**.
* **Atmospherics & Depth**: Elevation is simulated through **translucency, backdrop blurring, and radial spotlight glows** (`backdrop-filter` combined with dynamic cursor-tracking JS gradients) instead of flat shadows.
* **Milled Edges**: High-contrast 1px solid borders simulate a rigid, reliable wireframe aesthetic. Curvatures are strictly limited to `4px` (buttons/inputs) and `8px` (cards) to project technical engineering precision.

## 🛠️ Tech Stack & Dependencies

* **Core**: Semantic HTML5 structures and structured Vanilla Javascript.
* **Styling**: Tailwind CSS engine via CDN wrapper.
* **Iconography & Fonts**: Material Symbols Outlined, Google Fonts (Geist, JetBrains Mono).
* **Interactivity**: Dynamic coordinates cursor trackers, parallax graphics engines, custom validation handshakes.

## 🚀 Getting Started

The project runs natively as a zero-dependency, ultra-lightweight static ecosystem:

1. **Local View**:
   Simply double-click `index.html` or open it in any modern browser to view.
   
2. **Local Server (Recommended)**:
   For local development, spin up a lightweight HTTP server (e.g., using python, node, or live server extension):
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (npx)
   npx http-server .
   ```
   Open `http://localhost:8000` to view the website with fully active browser modules.
